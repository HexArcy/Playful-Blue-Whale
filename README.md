# 贪玩蓝鲸 🐋

大渣好，我系渣渣鲸！是兄弟就来喂我！

一个浏览器版「大鱼吃小鱼」小游戏：控制蓝鲸不断吃小鱼长大，小心别被比你大的鱼吃掉。

## 在线试玩

直接用浏览器打开 `index.html`，或启动任意静态服务器：

```bash
python -m http.server
# 然后访问 http://localhost:8000
```

无需安装依赖、无需构建。

## 玩法

- **目标**：吃小鱼长大，活得越久分越高，别被大鱼吃掉
- **小鱼**：吃掉加分并成长（无体型上限，越大镜头自动拉远）
- **金鱼**（金色）：+200 分，成长更多
- **绿宝石鱼**（绿色）：+100 分，回复 1 点生命
- **大鱼**（灰色）：比你大的鱼，碰到扣 1 命并被击退
- **连击**：2 秒内连续吃鱼叠加倍率（x1 → x1.5 → x2 → x2.5 → x3），断连归零
- **星星**（金色星形）：5 秒无敌，期间可撞吃任何大鱼
- **磁铁**（粉色）：5 秒内自动吸附附近小鱼（有粉色光环提示范围）
- **鱼钩**：随机从海面垂下，被钩住扣 1 命
- **金鱼潮**：随机触发，大量金鱼来袭
- **生命**：共 3 条命，归零游戏结束

## 养成系统

每局按得分结算金币（得分 ÷ 20），可永久升级：

生命上限、初始体型、成长速度、移动速度、连击窗口、道具时长、磁吸范围、磁吸速度、得分加成。

存档保存在浏览器 `localStorage`（键名 `twlj_*`），养成界面可一键删除存档。

## 技术栈

- 原生 JavaScript + HTML5 Canvas + CSS，零依赖、无构建
- WebAudio 振荡器合成音效（无音频文件）
- 存档：`localStorage`

## 项目结构

所有代码共享全局作用域，按 `index.html` 中的 `<script>` 顺序加载：

| 文件 | 职责 |
|---|---|
| `game-core.js` | 工具函数、升级系统、画布/相机、全局状态、音效 |
| `game-entities.js` | 场景装饰与鱼类/道具的生成 |
| `game-update.js` | 移动、碰撞、刷怪、鱼钩等全部模拟逻辑 |
| `game-render.js` | 所有 Canvas 绘制 |
| `game-ui.js` | HUD、界面流程、输入、主循环 |
